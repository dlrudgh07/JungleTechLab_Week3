# JungleTechLab 엔진 문서

Week2 팀 과제로 만들어진 **DirectX 11 기반 미니 게임 엔진 / 씬 에디터**입니다.
Week3부터 이 엔진을 공통 시작점으로 사용하기 때문에, 처음 보는 사람이
"어떻게 쓰는지"와 "왜 이렇게 만들어졌는지"를 빠르게 이해할 수 있도록 정리한 문서 모음입니다.

## 한 줄 요약

> 언리얼 엔진의 구조(UObject / Actor / Component / World)를 **최소한의 코드로 직접 구현**해 보면서,
> 엔진이 매 프레임 무슨 일을 하는지 눈으로 확인할 수 있게 만든 학습용 에디터 엔진.

## 빠른 시작

```
1. JungleTechLab_Week3.sln 을 Visual Studio 2022 이상에서 연다
2. 구성(Configuration)을 x64 / Debug 로 맞춘다
3. JungleTechLab_Week3 프로젝트를 시작 프로젝트로 지정하고 F5
4. 실행되면 왼쪽 패널의 Spawn 버튼으로 도형을 만들고, 우클릭 드래그로 카메라를 돌려 본다
```

자세한 내용은 [03. 사용 설명서](03_사용_설명서.md)를 참고하세요.

## 기술 스택

- **언어**: C++20 (MSVC, `/std:c++20`)
- **그래픽스**: DirectX 11 (`d3d11.lib`, `d3dcompiler.lib`)
- **UI**: Dear ImGui (DX11 + Win32 백엔드, `JungleTechLab_Week3/ImGui/`에 소스 동봉)
- **직렬화**: SimpleJSON 단일 헤더 (`JungleTechLab_Week3/Json/json.hpp`)
- **테스트**: googletest (NuGet, `Test/UnitTest`)
- **외부 의존성**: 위 4개가 전부. 별도 설치 없이 솔루션만 열면 빌드됩니다.
